# KPI definitions (clarified, in docs/decisions.md)
Line value = qty * unit_price * (1 - discount_pct). Net revenue = completed orders only.
Returns = value of returned orders. Orders = completed count. AOV = net revenue / orders.
COGS = qty * unit_cost on completed. Gross margin % = (net revenue - COGS) / net revenue.
Cancellation rate = cancelled / all orders. Return rate = returned / (completed + returned).
New customer = first-ever non-cancelled order in the period (only customers with a
non-cancelled order in the period count). Weeks Mon-Sun; months calendar.
Comparisons: daily vs same weekday last week; weekly vs previous week and same ISO week
last year; monthly vs previous month and same month last year. % for money/counts,
percentage points for rates. Every function takes an explicit as_of date.
